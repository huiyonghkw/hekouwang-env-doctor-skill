# 报告格式与对话流程

> 目标：用户看完**知道该动哪个、不该动哪个、动了要付什么代价**，并且每一步都由他自己拍板。
> 原则：**分组呈现、逐组确认**，不要把几十行清单一次性糊到用户脸上。

---

## 一、对话流程（四步，别跳步）

### 第 1 步 · 先给结论，不给清单

扫描完先回三句话：磁盘什么状况、发现多少可回收、最该看的是哪一条。

> 体检完了。你这台机器 460 GB 的盘用了 338 GB（79%）。
> 扫到约 50 GB 缓存与残留，其中 **9.9 GB 属于「你已经不用的工具」**——这部分是可以放心清的。
> 最该看的一条：`~/.nvm` 占 9.8 GB，但你的 node 实际来自 fnm，这个目录最后改动是 2025-03。

### 第 2 步 · 按身份分三组呈现（这一步是全器的核心）

**顺序固定：残留 → 缓存 → 数据。**先说能清的，再说可选的，最后说别碰的。

每一组给出小计，每一条包含五要素：**是什么 / 多大 / 凭什么这么判 / 官方命令 / 代价**。

### 第 3 步 · 逐组问，不要一次问完

一组问一次，用户答完再进下一组：

> 【残留组】这三条我判定为「你已经不用的工具」，合计 9.9 GB。
> 要我把清理命令列出来吗？还是想先看某一条的判定依据？

用户可以选：全要 / 只要某几条 / 先看依据 / 跳过。**用户没明确说要，就不要往下走。**

### 第 4 步 · 生成命令块，交给用户自己跑

用户确认后，把命令集中成一块，**并在块前写明「以下命令请你自己执行，我不会代跑」**。

## 二、报告模板

```markdown
## 开发环境体检报告

**磁盘**：<总量> / 已用 <x>（<pct>）/ 可用 <y>
**扫描口径**：<规则库版本> · 采集于 <时间> · 全程只读

| 身份 | 小计 | 说明 |
|---|---|---|
| 🟠 残留 | <x GB> | 属于你已经不用的工具，可放心清 |
| 🟡 缓存 | <x GB> | 在用，删了会重下 |
| 🔴 数据 | <x GB> | 删了找不回来，别碰 |

---

### 🟠 残留（建议优先处理）

#### 1. `~/.nvm` — 9.8 GB

- **是什么**：node 版本管理器 nvm 及其下载缓存
- **凭什么判残留**：shell 配置未加载 ✕ / 命令不在 PATH ✕ / node 实际由 **fnm** 提供 ✕ / 最后改动 2025-03-14（1 年 4 个月前）
- **补充**：其中 8.5 GB 是隐藏的 `.cache`（下载过的安装包），1.3 GB 是 4 个旧版本；其中 v16.20.2 与 fnm 里的重复
- **官方处置**（nvm README「Manual Uninstall」）：
  ```bash
  rm -rf "$HOME/.nvm"
  ```
  ⚠️ 删完记得删掉 shell 配置里的 `NVM_DIR` / `nvm.sh` / `bash_completion` 三行，否则每开终端都会报错
- **代价**：以后要用 nvm 需重装（但你已经在用 fnm）

---

### 🟡 缓存（空间紧张再清）

| 目录 | 体积 | 官方命令 | 代价 |
|---|---|---|---|
| `~/.npm` | 4.7 GB | `npm cache clean --force` | 下次装包重下 |
| … | | | |

---

### 🔴 数据（别碰，仅告知）

| 目录 | 体积 | 为什么别碰 |
|---|---|---|
| `~/.cache/huggingface` | 7.3 GB | AI 模型权重，重下要几小时 |
| Docker 容器 | 6.3 GB | 容器卷里可能有数据库数据 |

---

### ❓ 不确定（需要你判断）

- `~/.pyenv`（121 MB）：三个信号指向残留，但 `versions/` 下有一个 pypy3.10。**如果那是你特意留的，就别删。**

---

### 免责

- 以上判定基于扫描信号，**最终是否删除由你决定**；
- 清理命令请以各工具官方文档为准，**本体检器不代为执行**；
- 删除版本管理器目录后，记得同步清理 shell 配置里的初始化行。

<sub>规则库 <版本> · 本次扫描全程只读，未改动任何文件</sub>
```

## 三、写作口径

- **不吓唬**：不说「你的电脑正在被垃圾吞噬」这类话，就事论事报数字。
- **不夸大**：能回收多少就说多少，不把「缓存」算进「可回收」去凑大数。
- **给依据**：每条判定都要能追溯到具体信号，用户问「凭什么」时要答得出。
- **认不知道**：信号矛盾就进「不确定」组，别为了报告好看而下结论。
